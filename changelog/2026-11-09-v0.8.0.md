**`/exit` quits iota**, the way Ctrl+D does, instead of going to the model as
a message. **The first request after your laptop wakes up no longer sits on
"Waiting for the model"** for up to two minutes. And with any picker or
confirmation open, the pane now says iota is waiting on you, so whatever
watches it — herdr, a script — no longer types into the dialog.

## Added

- **`/exit` quits iota.** Typing it used to send the word to the model, at
  the cost of a full turn. Now it leaves the chat exactly as Ctrl+D does,
  with no confirmation — the session is saved as it goes. A bot quits on it
  too and keeps its session.

## Fixed

- **The first request after the computer wakes no longer stalls.** iota
  reused the connections it had open before the lid closed, which were long
  dead by morning, so the first request waited 20 seconds to two minutes on
  "Waiting for the model" before trying again. iota now notices that the
  machine slept and opens fresh connections before it sends.

- **The pane says iota is waiting on you while a picker or a confirmation is
  open.** Only a tool approval used to say so; with `/model`, `/new`,
  `/export` or any other dialog open, the pane read as idle, so whatever was
  watching it believed nobody was at the keyboard and could type into the
  dialog. Every dialog now reports that iota is waiting on you, and closing it
  reports what the turn is doing at that moment.
